A collaboration update saved by 0.1.x and reopened with its source file saves an unedited deck byte-identically again: run caps and colour-mapped `tx1`/`bg1` run colours are restored from the source for the text the 0.1.x seed wrote, in long and edited stories too, and the preset adjustments the 0.1.x seed stored as defaults, where no collaborator has changed them, move to the current defaults instead of drawing default stars as near-polygons. In JavaScript, a matching source that cannot be reattached now throws instead of opening a session that cannot save, and a save refuses rather than drop run baseline or spacing it could not recover.
