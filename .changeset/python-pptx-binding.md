`betteroffice-pptx` is a new PyPI package that puts the PPTX engine behind a typed Python API, next to `betteroffice-xlsx`. `Presentation.open` parses a deck into the same resident CRDT model the browser editor uses, and `snapshot`, `slide`, `story` and `media` read it back as plain Python objects — shapes with resolved fill and outline colours, geometry in EMU, text grouped into stories, paragraphs and runs, and embedded images as bytes you can write straight to disk. `insert_slide`, `move_slide`, `delete_slide`, `add_text_box`, `add_shape`, `move_shape`, `resize_shape`, `set_shape_fill`, `set_shape_stroke`, `set_shape_adjust`, `remove_shape`, `insert_text`, `delete_text`, `format_text` and `insert_paragraph_break` each return a receipt naming what changed, including the rect before and after a transform and the adjustment values after the engine clamped them. `register_font` and `render_slide` produce the renderer's display list as JSON, so a server can lay a slide out with the same contract the canvas paints. `open_collaborative`, `state_vector`, `state_as_update`, `diff` and `apply_update` are the same Yrs primitives the xlsx binding exposes, under the same names, so a project using both packages sees one contract.

Editing is in-memory for now. The engine serialises the parsed package rather than the edited model, so `save` and `save_path` refuse once a deck has been edited instead of handing back a file that quietly lost the work; an unedited deck still round-trips. An unsupported preset geometry, an unknown adjustment guide, an out-of-range client ID or an unknown parse limit raises `ValueError` rather than being ignored, a text range that crosses a paragraph boundary raises `RangeError`, and an oversized collaboration payload is refused before it is copied. Rendering refuses when no font has been registered, because nothing is embedded in this wheel.

A `Presentation` is bound to the thread that opened it: the engine's undo manager is not `Send`, so unlike `betteroffice-xlsx` this binding is `unsendable` and holds the GIL for the duration of a call. Give each worker its own presentation.
