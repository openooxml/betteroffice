Adds context menus for text, objects, tables, and slide thumbnails in the default worker editor, enabled by default. Adds `cut`, `copy`, `paste`, `deleteObject`, `deleteSlide`, `duplicateSlide`, `tableInsert`, and `tableDelete` commands and worker support for `duplicateSlide`.
