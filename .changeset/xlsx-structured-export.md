Add read-only structured export for XLSX. XLSX exports bounded sparse worksheet content and Markdown with positional anchors, formulas, stored values, formatted text, explicit hidden-content options, and omission diagnostics. Export does not recalculate formulas. `WorkbookHandle.exportStructured()` and `exportMarkdown()` return the content with the session version it was read at, or a typed refusal (`invalid-scope`, `invalid-options`, `limit-exceeded`) with `target` naming the sheet or `null`; `exportXlsxStructured`, `exportXlsxMarkdown` and `renderXlsxMarkdown` work from bytes or content without a session, reading bytes as stored with no clock. Sheet anchors carry the `sheetId` edit batches take in that session (`sheet:{index}` for bytes) beside the descriptive index and name, so a cell or range anchor's sheet id and A1 are its batch target at the exported version. Cells carry a typed value, the formula, the engine's display text, the number format and merge membership, and formula results are marked `unverified`, `missing` (none stored and nothing calculated since), `uncertain`, `cycle` or `limited`; sheets list merges, tables, hyperlinks, hidden row and column spans, and charts, pictures and shapes as placeholders with alt text and source-part provenance; defined names are listed read-only. Hidden sheets, rows, columns and names are opt-in, sheets whose visibility is unavailable (a model handed to `Workbook::from_model`, a replica's peers) are excluded as unknown unless added in the session, and comments, shared and inline rich-text runs, unsupported sheet content and unreadable charts are diagnosed; drawing objects keep their grid anchor while the rows and columns under them have not moved. `maxCells` and `maxBytes` stop at a complete record with `truncated`, and so does a retained part past a parser cap or the export's inspection budget. Markdown renders one labelled grid per sheet within row, column, cell and byte limits, escapes all document text and keeps it on one line, links hyperlinks only to `http`, `https` and `mailto` destinations checked after entity, percent and whitespace decoding, uses escaped HTML tables for merges, and returns the anchor of every `<!-- xlsx-export:N -->` marker. The Rust `Workbook` and the Python bindings expose the same API, and the renderer and exporter share the row and column visibility rules. `recalculate_all` now also moves the version, with a `Recalculation` event, when it changes which cells are in a cycle or at a limit, or on the first calculation of a file that stored formulas without results, so one version never exports two different contents.
