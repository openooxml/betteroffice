# @betteroffice/agents

## 0.1.0

### Minor Changes

- baeed82: Adds `@betteroffice/agents` with opt-in DOCX search, text proposals, raster previews and save/reopen checks. `createOfficeMcpServer` provides a local stdio MCP server with bounded file reads, tool inputs and image decoding.
- baeed82: Adds the opt-in `openXlsx` and `openPptx` prototypes and their MCP tools for cell/formula and slide text proposals, atomic acceptance, and proposed export.
- 7166688: Adds the `docx_edit` MCP tool and `DocxAgentDocument.edit` for direct, atomic DOCX edits: paragraph styles, bold/italic/underline on a grep match, paragraph insertion and deletion, and table row insertion and deletion. DOCX outline and read results give the table position of cell paragraphs.
- 8aa1269: Adds bounded PPTX outline, slide reading, atomic editing, PNG previews, and `attachPptx` for live presentation handles. Adds `duplicateSlide`, `setStoryParagraphs`, `fork`, and `layouts` to the presentation engine.
- 8aa1269: Adds bounded XLSX outline and range reading, versioned range, grid and sheet writes, formatting, find/replace and sort tools, PNG range previews, and `attachXlsx` for live workbook handles. Adds a `setCellValues` range step to the workbook engine.

### Patch Changes

- 8aa1269: Preserves existing cell, paragraph, run and notes formatting during edits. Adds optional `bullet` to `set_paragraphs`; `true` creates paragraph bullets, `false` removes them, and omitting it preserves existing bullets.
- db59bf8: Edit batches now write content into unlocked cells of protected sheets, and formats when the protection allows formatting cells. Locked cells stay refused. Values and formulas written into empty cells keep their row or column style, as typed input does.
