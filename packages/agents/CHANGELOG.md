# @betteroffice/agents

## 0.4.0

### Minor Changes

- 1d8ac98: Attached DOCX previews and async decisions honor editor ownership and expire touched references. Adds opt-in `expectPreviewVersion` guards and default `revision`, `stateVersion`, `decisionState` and `withdrawn` metadata for engine decision history.
- 3773773: Attached agent proposals use the shared engine; standalone behavior is unchanged. Adds opt-in DOCX `editPeer`, `proposeAsync`, `rejectAsync`, `discardAsync`, `keepRevisions`, `replaceText.at`, typed `TrackedRevisionConflictError`, `AcceptDateUnsupportedError` and `ProposalDecidedInEditorError`, and XLSX `getProposalStatus`, `onProposalChange` and `isProposalStale`.
- 3e7d0f6: Adds opt-in `setStoryParagraphs` proposals for paragraph rewrites with bullets, alignment, styled runs and `@ref` story targets. Review previews show inserted and deleted text and mark shapes changed by paragraph properties.
- c10ba8c: Adds opt-in `addTextBox`, `addShape`, `addPicture`, and `removeShape` proposals with local shape and story refs, insertion outlines, deletion strikes, and an 8 MB decoded media total limit. Exports `decodeBrowserPresentationImage` for browser image decoding without WASM.
- 3313017: Adds opt-in `setSlideLayout` and `setSlideBackground` proposals with `@ref` slide targets. Review previews show layout artwork and inherited picture backgrounds, with translated labels for both changes.
- c664499: Adds opt-in slide structure proposals with local refs, `proposalSlideStrip`, and `layoutProposalDiffSlideById`. The editor previews inserted, deleted, and moved slides before acceptance, and `office_propose` accepts slide structure edits for PPTX.
- 34b5676: Adds opt-in `insertTableRow`, `deleteTableRow`, `insertTableColumn`, and `deleteTableColumn` proposals, including Python proposal dictionaries. Review previews show table structure changes with translated labels, and acceptance applies the proposal as one undo step.
- 3e30099: Adds opt-in `reorderShape` proposals for moving shapes to the front, back, forward or backward, including Python dictionaries and agent tools. Review previews show the new stacking order with translated labels, and acceptance applies the proposal as one undo step.

### Patch Changes

- 00352fa: Adds `docx_read_runs` and `set_runs` for paginated DOCX reads and text edits that preserve run formatting. Optional `maxEdits` and CLI `--max-edits` raise the default 32-edit cap up to 500.
- 21d4394: `docx_edit` can now replace every occurrence of literal text inside an existing Word comment with `replace_comment_text`, keeping its author, anchor, formatting and thread state.
- 8f3f1fa: Adding, replying to or resolving a Word comment after accepting a proposal that changed a header or another part no longer fails with "Saving comments would change the unrelated package part".
- 5421e9e: `docx_edit` adds `delete_comment`, which removes a comment or a root comment's whole thread, including its range markers, reference and companion entries.
- ab5bb3b: docx_edit insert_paragraphs can now insert before a paragraph, copying its style and paragraph formatting like pressing Enter at its start in Word, with optional anchor run formatting from that paragraph.
- 1f2c008: Applying a paragraph style to a numbered paragraph now keeps its direct list numbering and direct formatting, and a paragraph numbered only by its old style stops being numbered, instead of refusing the change.
- 1282f77: Adds opt-in `set_language` edits for DOCX paragraphs, grep matches, styles and document defaults. Latin, East Asian and complex-script proofing language slots can be set or cleared independently while preserving other formatting.
- ea86df7: The MCP server now reports the package version in its initialize handshake instead of 0.0.0.
- 2f5f765: Adds `--formats` and `--tools` filters (with `BETTEROFFICE_MCP_FORMATS` and `BETTEROFFICE_MCP_TOOLS` env equivalents) to `betteroffice-mcp` and `createOfficeMcpServer`, so `tools/list` only exposes the tools a job needs.
- b98ef24: Uses native engines by default on Node, Bun and Deno for editing and PNG previews, with automatic WebAssembly fallback. Browsers keep WebAssembly; `@napi-rs/canvas` is now an optional peer needed only for fallback previews.
- 4a26887: Agent tools now explain that `match` takes a grep match ID rather than literal text, default tracked acceptance to the current date, and let PPTX `find_replace` target soft line breaks with the vertical tab character.
- 995c141: `office_verify` on DOCX now compares the saved file with the original: parts, element counts, field instructions, drawings and relationships. Losses the edits do not explain are listed and set `structure.ok` to false. Pass `structure: false` to skip it.
- 4592a3a: Accepted DOCX text replacements now coalesce adjacent changed runs with identical written properties by default. Untouched run splits, markers, fields and tracked revisions are preserved.
- 02bd5be: DOCX uses installed font packs by default for characters they cover. Uncovered scripts and unavailable CJK families retain browser and Google Fonts fallbacks unless disabled; configured fonts and document embeds still take precedence.
- f30d46e: `set_paragraph_style` keeps borders, spacing and other properties inherited from the new style when saving an unnumbered paragraph, so later style changes continue to apply.
- 308f7b3: Preserves SmartArt during agent and editor saves, including resized diagrams and large source payloads. `Shape.drawingXml` or `Shape.drawingRunXml` stores the source once; `Shape.drawingModel` tracks frame edits. Enabled by default.
- d1fff89: DOCX saves keep untouched paragraphs unchanged after more agent and editor edits: inserts next to tables, content controls, bookmarks and comment ranges, and cell merges in plain tables. Text edits keep a direct automatic text color and the original runs.
- dfd1833: Agent presentation exports no longer depend on a prior slide preview: edited autofit text is always shrunk to fit on save. `PresentationHandle.save` accepts `{ fonts, fallbackFonts }` to fit with those faces. Saving edited autofit text no longer scans a slide's shapes quadratically.
- e6d5c52: Package exports now carry a `default` condition next to `import`, so webpack consumers (`next build --webpack`, including editors loaded with `next/dynamic`) resolve every entry instead of failing with "Package path is not exported".
- 3adc24b: Breaking: workbook `renderPng(viewport)` and `renderRangePng(options)` become `await renderPng({ sheet, viewport } | { sheet, range }, { scale, maxWidth, maxHeight })`, painted with the editor's painter on a canvas. It rejects with `PngExportError` rather than substitute a font.
- 14b82ff: Shown and returned formula text drops Excel's storage prefixes (`_xlfn.`, `_xlws.`, `_xlpm.`, `_xleta.`): the formula bar, `readCells`, structured export, defined names, conditional formats, agent reads and Python `formula()` give `=SEQUENCE(2,2)`. Saved files keep the prefixes; re-committing a shown formula leaves the cell unchanged.
- 9d433be: Formulas written in BetterOffice that use newer Excel functions (XLOOKUP, IFS, LET, LAMBDA, FILTER and others) are saved with the `_xlfn.` prefixes Excel expects, so Excel no longer opens them as #NAME?. Unedited formulas keep their exact text.

## 0.2.0

### Minor Changes

- 38016d1: `docx_edit` can merge table cells: `merge_cells` takes paragraph refs from two corner cells and merges the rectangle between them, keeping every paragraph in reading order. DOCX outline and read results give `rowSpan` and `colSpan` for merged cells.
- 67c7645: Adds `add_comment`, `reply_comment`, and `resolve_comment` to `pptx_edit`. PPTX discussions are available through `office_outline` with `story: 'comments'` and `office_read`; duplicated slides include independent discussions. Resolving requires modern comments.
- 24f4c8b: Makes PPTX shape targets infer slides and improves operation errors. Read tools clamp page sizes and `date` accepts calendar dates. Breaking: `set_slide_layout` receipts rename `mapping` to `placeholders`. Adds optional `sheet` defaults to `xlsx_write_range` and `shape` scopes to PPTX `find_replace`.
- fefa072: Adds `insertTableRow`, `deleteTableRow`, `insertTableColumn` and `deleteTableColumn`, plus matching `pptx_edit` operations. Edits keep formatting, refresh refs and undo. They are refused in collaborative sessions, on merged tables and for cells with text fields. New cells take one line.
- d72abd4: Adds chart discovery and atomic title and series edits, available by default. Use `charts` and `editCharts`, or the agents tools `xlsx_list_charts`, `xlsx_read_chart_text` and `xlsx_edit_charts`, to replace or remove titles, rename series and change category or value references on unshared chart parts.

- 85a699f: Updates Zod to fix a memory exhaustion vulnerability when validating oversized MCP tool inputs.
- 4c020da: Conditional formats keep italic text: opening, saving and recovery preserve `<i/>` in differential formats, `DifferentialFormatInput` and `ConditionalFormatInfo.format` gain `italic`, and the agent conditional format tools accept and list it. Recovery data from earlier releases still restores.

## 0.1.0

### Minor Changes

- 632b42e: Adds comment discovery through `office_outline` with `story: 'comments'` and `reply_comment` and `resolve_comment` operations in `docx_edit`. Adds `updateComment` to DOCX sessions for metadata edits.
- 3b96e48: Adds an opt-in `add_comment` op to `docx_edit` and `DocxAgentDocument.edit`, which anchors a Word comment on one grep match. Each line of the comment text becomes a paragraph.
- 4d0b2e2: Adds opt-in `runFormat: 'anchor'` to `docx_edit` `insert_paragraphs` to copy the anchor's first plain run formatting; style formatting remains the default.
- 07709cb: `docx_edit` `insert_paragraphs` takes `list: 'continue'` to add items after a list item at the same level, with its numbering, style and paragraph formatting. DOCX outline entries of list paragraphs include a zero-based `list.level`.
- 9d18c7b: Adds opt-in `insert_section_break` and `set_section` edits with section listings in `office_outline`. DOCX sessions add `insertSectionBreakAfter`, `setSectionProperties` and `listSections` for section starts, orientation, page size and margins.
- c688743: First release: agents get bounded tools to outline, read, search and edit DOCX, XLSX and PPTX files, propose changes, render PNG previews, and verify saving and reopening. Includes `attachXlsx` and `attachPptx` live handles and a local stdio MCP server, `createOfficeMcpServer`.
- 8348fa0: `pptx_edit` `move_slide` takes `after` or `before` a slide ID as an alternative to `index`, so a slide can be placed next to another without position arithmetic. Saved decks keep every slide's `p:sldId` across reorders, and inserted slides take IDs above all existing ones.
- f18a42d: Adds opt-in `setSlideLayout` and the `pptx_edit` operation `set_slide_layout` to change a slide’s layout with explicit placeholder mappings. Layout inventories include placeholder IDs and names; unmapped shapes keep their data and geometry.
