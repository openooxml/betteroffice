DOCX, XLSX, and PPTX each provide a framework-free core, a React editor, and
locale strings under the `@betteroffice` scope. Their `-native` packages call
the Rust facades directly from Node.js and Bun.

```bash
npm install @betteroffice/docx-react @betteroffice/docx react react-dom
```

`react` and `react-dom` (18 or 19) are peer dependencies of every `-react`
package.

## Add a React editor

```tsx
import { DocxEditor } from "@betteroffice/docx-react";
import "@betteroffice/docx-react/styles.css";

<DocxEditor documentBuffer={bytes} onSave={(saved) => upload(saved)} />;
```

`documentBuffer` accepts an `ArrayBuffer`, `Uint8Array`, `Blob`, or `File`.
Without `onSave`, File > Save downloads the edited bytes. Configure
[fonts](./packages#fonts) before mounting the DOCX editor for consistent text
measurement and pagination.

The spreadsheet and presentation editors take a `Uint8Array`:

```tsx
import { XlsxEditor } from "@betteroffice/xlsx-react";
import { PptxEditor } from "@betteroffice/pptx-react";

<XlsxEditor file={bytes} fileName="report.xlsx" />
<PptxEditor file={bytes} fonts={[{ family: "Inter", bytes: fontBytes }]} />
```

`PptxEditor` requires at least one font face in `fonts` before it can lay out text.

## Use the JavaScript core

```ts
import { initWasm, openWorkbook, paintDisplayList } from "@betteroffice/xlsx";

await initWasm();
const workbook = openWorkbook(new Uint8Array(await file.arrayBuffer()));

const frame = workbook.displayList({ x: 0, y: 0, width: 800, height: 600 });
paintDisplayList(canvas.getContext("2d")!, frame, devicePixelRatio);

workbook.editCell(0, 9, 2, "=SUM(C1:C9)");
const saved = workbook.save();
```

`initWasm()` fetches the packaged wasm asset once in browsers; pass wasm bytes or
a precompiled `WebAssembly.Module` in runtimes that cannot fetch that URL. The
core also provides hit-testing, viewport calculations, accessibility data, and
TSV clipboard helpers.

## Run natively in Node.js and Bun

```bash
npm install @betteroffice/xlsx-native
```

```ts
import { readFile } from "node:fs/promises";
import { openWorkbook } from "@betteroffice/xlsx-native";

const workbook = await openWorkbook(await readFile("report.xlsx"));
await workbook.set(0, "B10", "=SUM(B1:B9)");
const png = await workbook.renderSheet({ sheet: 0, range: "A1:F20" });
const saved = await workbook.save();
```

```ts
import { openWorkbook } from "@betteroffice/xlsx-native";

const workbook = await openWorkbook(Buffer.from(await Bun.file("report.xlsx").arrayBuffer()));
await Bun.write("out.xlsx", await workbook.save());
```

The native packages accept and return `Buffer`, expose ordinary camel-cased
objects, and run facade operations asynchronously in call order without blocking
the JavaScript event loop. Platform binaries are optional dependencies selected by npm, so
installing needs no Rust toolchain and downloads no executable at install time.
The packages run under Node.js and Bun.
Use `@betteroffice/docx-native`, `@betteroffice/xlsx-native`, or
`@betteroffice/pptx-native` for the corresponding Rust facade.

The unsuffixed `@betteroffice/<format>` packages remain the portable
WebAssembly core, which also runs in Node.js; the `-native` packages execute
the same underlying Rust engine as prebuilt native binaries instead. Headless parsing
and editing work in both runtimes without a browser or canvas — the native
packages additionally render PNGs without one.

## Package reference

| Package | What it is |
| --- | --- |
| `@betteroffice/docx` | Framework-free DOCX core: OOXML parse and serialize, CRDT editing, text shaping, pagination, canvas rendering. Saving preserves untouched package parts. |
| `@betteroffice/docx-react` | The DOCX editor and viewer as a React component: toolbar, paginated canvas, comments, tracked changes. |
| `@betteroffice/docx-i18n` | UI locale strings and types for the DOCX React editor. |
| `@betteroffice/docx-native` | Native Node.js/Bun binding for DOCX inspection, editing, layout, PNG rendering, and saving. |
| `@betteroffice/xlsx` | Framework-free XLSX core: SpreadsheetML parse and serialize, formula recalculation, grid display lists, hit-testing, PNG export, and reviewable agent proposals. |
| `@betteroffice/xlsx-react` | The spreadsheet editor and viewer as a React component. |
| `@betteroffice/xlsx-i18n` | UI locale strings and types for the XLSX React editor. |
| `@betteroffice/xlsx-native` | Native Node.js/Bun binding for XLSX calculation, editing, collaboration, proposals, PNG rendering, and saving. |
| `@betteroffice/pptx` | Framework-free PPTX core: parsing, editing, masters and layouts, rendering, comments, collaboration, and saving. Untouched slides retain their source bytes. |
| `@betteroffice/pptx-react` | The slides editor and viewer as a React component. |
| `@betteroffice/pptx-i18n` | UI locale strings and types for the PPTX React editor. |
| `@betteroffice/pptx-native` | Native Node.js/Bun binding for PPTX inspection, editing, collaboration, proposals, PNG rendering, and saving. |

See [Collaboration](./collaboration) to connect editors through a shared relay.
