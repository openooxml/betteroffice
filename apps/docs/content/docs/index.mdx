---
title: BetterOffice
description: Browser-native DOCX, XLSX, and PPTX editors, plus VSDX support in development
---

BetterOffice provides Rust and WebAssembly document engines with framework-neutral
core packages and React editors.

VSDX support is in development. Its framework-free core parses, resolves,
renders, round-trips, and transactionally edits `.vsdx` packages; no React editor
or live demo is available yet.

## Guides

- [Collaboration](./collaboration): connect DOCX, XLSX, and PPTX editors through
  a shared transport and deploy a Cloudflare Durable Object relay.
