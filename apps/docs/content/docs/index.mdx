BetterOffice lets you open, edit, render, and save documents, spreadsheets, and
slides. Embed a React editor in your app, build on the JavaScript cores, or use
the Rust and Python APIs for server-side processing.

[Try the demo](https://demo.betteroffice.dev) or choose a guide to get started.

## Guides

- [Packages](./packages): choose packages for your language and file format.
- [JavaScript](./javascript): install a React editor or use the framework-free core.
- [Rust](./rust): open, edit, render, and save files with native APIs.
- [Python](./python): work with DOCX, XLSX, and PPTX files from Python.
- [Collaboration](./collaboration): connect editors and deploy a relay.
