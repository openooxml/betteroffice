title: Visio VSDX
description: Work with Visio diagrams using the source-preview packages
---

VSDX support is available from source. [Try the diagram editor](https://demo.betteroffice.dev/vsdx)
or build the packages from the repository. The packages are not yet published on
npm, crates.io, or PyPI.

## Rust packages

See the [crate READMEs](https://github.com/openooxml/betteroffice/tree/main/crates/betteroffice-vsdx)
for API details and supported operations.

| Crate | Purpose |
| --- | --- |
| `betteroffice-vsdx` | Native facade |
| `betteroffice-vsdx-parse` | Package parsing and lossless XML |
| `betteroffice-vsdx-resolve` | ShapeSheet inheritance |
| `betteroffice-vsdx-eval` | Formula evaluation |
| `betteroffice-vsdx-render` | Display lists |
| `betteroffice-vsdx-edit` | Transactional editing and collaboration |
| `betteroffice-vsdx-formula` | Bounded formula parsing |

## JavaScript and React

`@betteroffice/vsdx` provides the Wasm engine and Canvas display-list painter. Initialize the Wasm module before opening a diagram.

`@betteroffice/vsdx-react` provides the React editor. Its strings are supplied by `@betteroffice/vsdx-i18n`. Pass font bytes to the editor so layout and painting use the same faces.

## Python

The Python binding reads pages, shapes, cells, and connections. Build it from a
repository checkout:

```bash
python -m pip install ./bindings/python-vsdx
```

VSDX files are not supported by the redaction CLI.
