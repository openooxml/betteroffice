The VSDX engine processes Visio diagram packages. Support is under development; the crate READMEs describe the supported operations and remaining limitations.

| Crate | Purpose |
| --- | --- |
| `betteroffice-vsdx` | Native facade |
| `betteroffice-vsdx-parse` | Package parsing and lossless XML |
| `betteroffice-vsdx-resolve` | ShapeSheet inheritance |
